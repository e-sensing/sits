# Function to reset sits color table

Resets the color table

## Usage

``` r
sits_colors_reset()
```

## Value

No return, called for side effects

## Author

Gilberto Camara, <gilberto.camara@inpe.br>

## Examples

``` r
if (sits_run_examples()) {
    # reset the default colors supported by SITS
    sits_colors_reset()
}
```
