# Check is date is valid

Check is date is valid

## Usage

``` r
.check_date_parameter(
  x,
  len_min = 1L,
  len_max = 1L,
  allow_null = FALSE,
  msg = NULL
)
```

## Arguments

- x:

  parameter to be checked

- len_min:

  minimum length of vector

- len_max:

  maximum length of vector

- allow_null:

  allow NULL?

- msg:

  Error message

## Value

Called for side effects.
