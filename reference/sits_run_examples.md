# Informs if sits examples should run

This function informs if sits examples should run. To run the examples,
set "SITS_RUN_EXAMPLES" to "YES" using Sys.setenv("SITS_RUN_EXAMPLES" =
"YES") To come back to the default behaviour, please set
Sys.setenv("SITS_RUN_EXAMPLES" = "NO")

## Usage

``` r
sits_run_examples()
```

## Value

A logical value
